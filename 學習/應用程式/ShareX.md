最近發現 snagit 越來越難用
1. 不能一開機就使用
2. 開啟速度越來越慢
3. 用久了，還會給我要當不當的，火大死了.

今天查了一下，有 sharex 這個軟體可以用，大家都說好用，但實際上手並不像 snagit 那麼直接，需要熟悉適應一下。

首先要調整的地方就是
## 一截圖需要直接有編輯工具
叫出主畫面後，有一個 "截取後的排程"
-> 開啟圖片編輯
-> 將圖片複製到剪貼簿
-> 複製檔案路徑

## 設定文字字型
### 一般文字
直接設定就好
-> 選的字型不要太粗
-> border color 設成 "FFFFFF00" 透明，不然會看不清楚
-> 線條粗細也要調整
## speech ballon 語音氣泡的設定
大同小異，主要是
-> 背景色，設成灰的
-> 字型設定
-> 邊框也可以調整，corner radius 直角或不同的彎都可以。
選定工具，就有對應的選項可以調整。

## 截圖快捷鍵設定
找到 "快捷動作" 去自訂。
