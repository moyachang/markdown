# 這是什麼用法?
```java=
return rolMemsByMemId.entrySet().stream()  
        .map(entry -> toProjectMember(entry.getKey(), entry.getValue(), rolNameById))  
        .toList();
```

        
這段程式碼是 Java 8+引進並在 **Java 16** 進一步簡化的 **Stream API 函數式程式設計（Functional Programming）** 用法。
主要功用是：**將一個 Map 的資料逐筆轉換格式，最後收集成一個 List 返回。**

### 詳細拆解說明

1. **`rolMemsByMemId.entrySet().stream()
    - `rolMemsByMemId` 是一個 `Map<K, V>`。       
    - `.entrySet()` 取得 Map 裡所有的鍵值對（`Entry<Key, Value>`）。          
    - `.stream()` 將這個集合轉換成 **Stream（資料流）**，讓你可以對裡面的元素進行鏈式處理。
2. **`.map(entry -> toProjectMember(entry.getKey(), entry.getValue(), rolNameById))`**      
    - `.map()` 是 **映射 / 轉換** 的意思。它會走訪 Stream 中的每一個 `entry`，並透過傳入的 Function 將其轉換成新的物件。        
    - `entry.getKey()`：取得 Map 的 Key（例如會員 ID）。
    - `entry.getValue()`：取得 Map 的 Value（例如角色資料或相關資訊）。
    - `toProjectMember(...)`：呼叫自訂的轉化方法，傳入 Key、Value 以及外部的 `rolNameById`（角色名稱對照表），將資料封裝成一個新的 `ProjectMember` 物件。
3. **`.toList()`**
    - 將 Stream 中處理完的所有 `ProjectMember` 物件收集起來，包裝成一個 **不可變（Unmodifiable）的 `List<ProjectMember>`** 並回傳。
    - 💡 _註：`.toList()` 是 **Java 16** 新增的簡化寫法。在 Java 11（含）以前，這裡通常寫成 `.collect(Collectors.toList())`。_

### 等價傳統寫法比較（for 迴圈）

如果不使用 Stream API，這段程式碼用傳統的 `for` 迴圈寫法如下：
Java

```java=
List<ProjectMember> result = new ArrayList<>();
for (Map.Entry<KeyType, ValueType> entry : rolMemsByMemId.entrySet()) {
    ProjectMember member = toProjectMember(entry.getKey(), entry.getValue(), rolNameById);
    result.add(member);
}
return Collections.unmodifiableList(result); // 對應 .toList() 的不可變特性
```

**總結：** 使用 Stream 可以讓代碼更簡潔、直觀（宣告式程式設計 Declarative Programming），表達出「**走訪 Map -> 轉成物件 -> 組成 List**」的操作意圖。


```java=
Map<String, String> rolNameById = up4ProjectRolRepository.findByProjectId(projectId).stream()
                .collect(Collectors.toMap(Up4ProjectRol::rolId, Up4ProjectRol::rolName));
```

這段程式碼同樣是 **Java Stream API** 的常見用法，主要功能是：**將從資料庫查出來的物件清單（List），轉換成一個以 `rolId` 為 Key、`rolName` 為 Value 的 `Map<String, String>` 查找表（Lookup Table）**。
這通常用於快速搜尋或加速後續的資料對照（例如在上一題程式碼中作為 `rolNameById` 傳入）。
### 詳細拆解說明

1. **`up4ProjectRolRepository.findByProjectId(projectId)`**
    - 呼叫 Repository 從資料庫查詢該 `projectId` 下所有的專案角色清單。
    - 回傳類型通常是 `List<Up4ProjectRol>`。
2. **`.stream()
    - 將 `List<Up4ProjectRol>` 轉成 **Stream（資料流）** 以進行後續處理。
3. **`.collect(Collectors.toMap(...))`**  
    - `.collect()` 是 Stream 的終端操作（Terminal Operation），用來將 Stream 裡的資料匯總收集起來。
    - `Collectors.toMap(KeyMapper, ValueMapper)` 是專門拿來把資料轉成 `Map` 的收集器，需要傳入兩個函數：
        - **第一個參數（KeyMapper）：`Up4ProjectRol::rolId`**
            - 指定要用 `Up4ProjectRol` 物件的 `rolId` 作為 Map 的 **Key**。    
        - **第二個參數（ValueMapper）：`Up4ProjectRol::rolName`** 
            - 指定要用 `Up4ProjectRol` 物件的 `rolName` 作為 Map 的 **Value**。
    - _註：`Up4ProjectRol::rolId` 是 Java 的 **方法參考（Method Reference）**，等同於寫 `rol -> rol.rolId()`。_
### 等價傳統寫法比較（for 迴圈）

### ⚠️ 注意事項（踩坑提醒）

使用 `Collectors.toMap` 時有兩個非常常見的陷阱需要注意：  
1. **如果 Key 重複，會拋出例外（`IllegalStateException`）**：
    - 如果資料庫查出來的資料中有兩筆資料擁有相同的 `rolId`，`Collectors.toMap` **預設會直接報錯崩潰**。
    - **解決方式**：若有可能重複，需要提供第三個參數（衝突合併策略），例如遇到重複時保留後者：
        ```java=
        .collect(Collectors.toMap(
            Up4ProjectRol::rolId, 
            Up4ProjectRol::rolName, 
            (oldValue, newValue) -> newValue // Key 重複時以新的 Value 覆蓋
        ));
        ```
        
1. **如果 Value 為 `null`，會拋出 `NullPointerException`**：
    - 如果某筆資料的 `rolName` 為 `null`，`Collectors.toMap` 底層使用的是 `HashMap.merge()`，會直接拋出 NPE。

Map<String, List<Up4ProjectRolMem>> rolMemsByMemId = projectRolMems.stream()

這段程式碼的功能是：**將一個角色人員清單（`projectRolMems`），依據「會員 ID（`memId`）」進行分類（Group By），組合出一個 `Map<String, List<Up4ProjectRolMem>>`**。
這通常用於**一對多**的資料分類情境（例如：一個會員可能同時擁有「管理者」、「一般成員」等多個專案角色）。
### 詳細拆解說明

1. **`projectRolMems.stream()
    - `projectRolMems` 是一個 `List<Up4ProjectRolMem>`。
    - `.stream()` 將清單轉為 **Stream（資料流）** 以進行後續處理。  
2. **`.collect(Collectors.groupingBy(...))
    - `Collectors.groupingBy()` 是 SQL 中 `GROUP BY` 在 Java Stream API 中的對應實現。
    - 傳入的參數 **`Up4ProjectRolMem::memId`** 是分類的依據（Classifier）：
        - **Map 的 Key**：會是分類的依據，也就是 `memId`（會員 ID）。
        - **Map 的 Value**：會是所有擁有該 `memId` 的 `Up4ProjectRolMem` 物件所組成的 **`List`**。
### 等價傳統寫法比較（for 迴圈）

如果不使用 Stream API，這段程式碼用傳統的 `for` 迴圈寫法如下：

```Java
Map<String, List<Up4ProjectRolMem>> rolMemsByMemId = new HashMap<>();

for (Up4ProjectRolMem item : projectRolMems) {
    String memId = item.memId();
    
    // 如果 Map 裡還沒有這個 memId 的 List，就先建立一個新的 List
    if (!rolMemsByMemId.containsKey(memId)) {
        rolMemsByMemId.put(memId, new ArrayList<>());
    }
    
    // 將當前項目加入對應 memId 的 List 中
    rolMemsByMemId.get(memId).add(item);
}
```

_( Java 8 之後傳統寫法也可以簡化為 `rolMemsByMemId.computeIfAbsent(memId, k -> new ArrayList<>()).add(item);` )_
