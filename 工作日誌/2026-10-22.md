# 09) 編輯專案組織樹狀結構(企業夥伴)
## 重點
> 我現在要做另一個 api，要傳入的就是非ORG的組織，我叫他企業夥伴。
但這企業夥件的組成人員，可能會包含兩種型態，分別是 "PTS", "PTM"，所以在 employee 的內容，也會有所差別。
也就是會分成 MemberInfo, MemberInfoManual
請問是否也是類似作法

對，**樹的同步流程可以沿用 ORG 的做法**，差別主要在人員資料的接收與處理：

| 項目               | ORG API | 企業夥伴 API                        |
| ---------------- | ------- | ------------------------------- |
| 職務樹類型            | `ORG`   | `NON_ORG`                       |
| 人員類型             | `ORG`   | `PTS`、`PTM`                     |
| 人員內容             | 一般人員資料  | `MemberInfo`、`MemberInfoManual` |
| 異動紀錄 `isPartner` | `false` | `true`                          |

不過，現有的 `RoleMember`、`MemberInfo`、`MemberInfoManual` 位於 `application.result`，是**回傳資料的模型**。接收 API 輸入時，建議另外建立 Request 型別，採用相同的多型概念：

```java
@JsonTypeInfo(
        use = JsonTypeInfo.Id.NAME,
        include = JsonTypeInfo.As.PROPERTY,
        property = "memType")
@JsonSubTypes({
        @JsonSubTypes.Type(value = PartnerEmployeeRequest.class, name = "PTS"),
        @JsonSubTypes.Type(value = ManualPartnerEmployeeRequest.class, name = "PTM")
})
public sealed interface PartnerMemberRequest
        permits PartnerEmployeeRequest, ManualPartnerEmployeeRequest {

    String memId();
    String name();
}
```

樹節點就可以接收混合的人員清單：

```java
private List<PartnerMemberRequest> employees;
```

Jackson 會依每筆 JSON 的 `memType`，轉成對應的 Request 類別。

處理時再區分：

- **共同流程**：利用 `memId` 同步 `UP4_PROJECT_ROL_MEM`，寫入 join／leave 紀錄。
- **PTS**：處理一般企業夥伴的姓名、頭像等欄位。
- **PTM**：處理手動企業夥伴的姓名、email、公司等欄位；若允許在此 API 新增或修改手動人員，還要同步其資料表。

另外，查詢既有人員要同時包含兩種類型：

```java
findByMemberTypes(
        projectId,
        rol.rolId(),
        MemberType.nonOrganizationCodes());
```

所以可以沿用「同步樹」的架構，但人員部分要用多型 Request 接收，並分開處理 PTS、PTM 的差異。

可以先建立共用的 builder，再用 `instanceof` 補上 PTS 專有欄位：

```java
var log = UP4ProjectMemLog.builder()
        .projectId(projectId)
        .version(version)
        .memId(employeeRequest.getMemId())
        .memName(employeeRequest.getName())
        .rolId(rol.rolId())
        .rolName(rol.rolName())
        .isPartner(true)
        .updatedAt(System.currentTimeMillis())
        .activity("join");

if (employeeRequest instanceof ProjectPartnerPtsEmployeeRequest pts) {
    log.avatar(pts.getAvatar())
            .orgPathId(pts.getOrgPathId())
            .orgPathName(pts.getOrgPathName());
}

up4ProjectMemLogRepository.save(log.build());
```

PTS 會記錄頭像與組織路徑；PTM 沒有這些欄位，預設為 `null`。

另外，**PTS、PTM 都是企業夥伴，所以 `isPartner` 應設定為 `true`**。目前紀錄模型沒有 `email`、`company`，若也要保留 PTM 的這些異動資料，才需要擴充紀錄欄位。
