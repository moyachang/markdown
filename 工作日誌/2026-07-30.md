| **欄位名稱**           | **型態**           | **範例值**        | **說明**                                             |
| ------------------ | ---------------- | -------------- | -------------------------------------------------- |
| **id**             | String           | `"ST123"`      | 任務唯一識別碼 (ID)                                       |
| **parentId**       | String           | `"MT123"`      | 上層父任務/階段的 ID                                       |
| **type**           | String           | `"subTask"`    | 任務階層類型（例：`subTask` 子任務、`mainTask` 主任務、`phase` 階段）  |
| **name**           | String           | `"子任A"`        | 任務名稱                                               |
| **status**         | String           | `"running"`    | 任務狀態（例：`todo` 未開始、`running` 進行中、`completed` 已完成）   |
| **priority**       | String           | `"high"`       | 優先權/重要度（例：`high` 高、`medium` 中、`low` 低）             |
| **completion**     | Number           | `0`            | 完成進度百分比（範圍：0 ~ 100）                                |
| **completeDate**   | String           | `""`           | 實際完成日期 (YYYY-MM-DD)。若狀態改為已完成會自動填入，非完成狀態則為空字串       |
| **startDate**      | String           | `"2025-12-01"` | 預計開始日期 (YYYY-MM-DD)                                |
| **endDate**        | String           | `"2025-12-30"` | 預計結束日期 (YYYY-MM-DD)                                |
| **duration**       | String / Number  | `"10"`         | 工期天數                                               |
| **order**          | Number           | `1`            | 同階層任務的排序序號                                         |
| **isMilestone**    | Boolean          | `false`        | 是否設定為里程碑 (`true`: 是, `false`: 否)                   |
| **memberList**     | Array[Object]    | `[]`           | 指派的任務成員清單（物件內通常包含 `memId`, `isOwner`, `memType` 等） |
| **connectionList** | Array[Object]    | `[]`           | 任務前後置關聯/連動設定清單                                     |
| **縮寫**             | **全名**           | **白話核心邏輯**     | **最常用場景/關鍵字**                                      |
| **FS**             | Finish-to-Start  | **先完工，後開工**    | 最普遍的接續性任務                                          |
| **SS**             | Start-to-Start   | **先開工，後開工**    | 兩任務平行/同步進行                                         |
| **FF**             | Finish-to-Finish | **先完工，後完工**    | 兩任務同時收尾/交付                                         |
| **SF**             | Start-to-Finish  | **先開工，後完工**    | 人員交接、新舊系統替換                                        |

| 欄位               | 型別          | 說明                                                                     |
| ---------------- | ----------- | ---------------------------------------------------------------------- |
| `id`             | String      | 任務唯一識別碼                                                                |
| `parentId`       | String／null | 父節點 ID；若為最上層節點則為 `null` 或專案 ID，需統一規則                                   |
| `type`           | String      | 任務階層類型：`phase` 階段、`mainTask` 主任務、`subTask` 子任務                         |
| `name`           | String      | 任務名稱                                                                   |
| `status`         | String      | 任務狀態：`ready` 未開始、`running` 進行中、`suspend` 暫停、`finished` 已結束、`audit` 審核中 |
| `priority`       | String      | 優先權：`high` 高、`normal` 普通、`low` 低                                       |
| `completion`     | Integer     | 完成度，建議範圍為 `0～100`                                                      |
| `completeDate`   | String／null | 實際完成日期，格式為 `yyyy-MM-dd`；尚未完成時建議回傳 `null`                               |
| `startDate`      | String      | 計畫開始日期，格式為 `yyyy-MM-dd`                                                |
| `endDate`        | String      | 計畫結束日期，格式為 `yyyy-MM-dd`                                                |
| `duration`       | Integer     | 任務工期，需另行定義單位及是否排除假日                                                    |
| `order`          | Integer     | 同一父節點下的顯示順序值                                                           |
| `isMilestone`    | Boolean     | 是否為里程碑任務                                                               |
| `memberList`     | Array       | 任務成員清單；沒有成員時回傳空陣列                                                      |
| `connectionList` | Array       | 任務關聯設定清單；沒有關聯時回傳空陣列                                                    |
